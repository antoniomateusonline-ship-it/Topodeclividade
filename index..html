02Visualização

Declividade positiva = subida, negativa = descida, no sentido "De → Para". Distância inclinada = √(dist. horizontal² + Δz²). Proporção do talude = 1 : (100 / declividade). Clique em qualquer valor do relatório para editá-lo; use as setas para reordenar os itens.
